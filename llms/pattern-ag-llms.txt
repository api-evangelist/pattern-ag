# Pattern Ag

> Pattern Ag was a predictive-agronomy company (Emeryville, California; founded 2018)
> that used DNA sequencing and soil metagenomics to forecast pest, pathogen and
> nutrient-deficiency pressure a season ahead. In August 2024 it merged with
> EarthOptics. The combined company operates as EarthOptics and the Pattern Ag brand
> has been retired.

## Status of this profile

- The Pattern Ag brand is **retired**. `https://www.pattern.ag/` returns HTTP 301 to
  `https://www.earthoptics.com` (verified 2026-08-26); every Pattern Ag deep link
  probed returned 404, and the Pattern Ag LinkedIn page redirects to an EarthOptics
  company page.
- Pattern Ag published **no public API**: no developer portal, no API reference, no
  OpenAPI/AsyncAPI/GraphQL contract, no SDKs, no MCP server and no agent card were
  ever published under the pattern.ag domain, and none survive today.
- The pattern.ag domain itself is still registered and mail-active (Google Workspace
  MX, SPF including HubSpot), but serves no web content of its own.

## Where the surface went

- Successor company: EarthOptics — https://earthoptics.com/
- EarthOptics runs a customer-facing application at https://app.earthoptics.com/
  backed by a **private** REST API at `https://api.earthoptics.com` (Django REST
  Framework + gunicorn). Its drf-spectacular OpenAPI schema endpoint
  `/api/schema/` and Swagger UI `/api/docs/` both return HTTP 401 — the
  machine-readable contract exists but is not publicly retrievable.
- That surface is profiled separately and belongs to EarthOptics, not to Pattern Ag:
  https://apis.io/providers/earth-optics/

## Integrations Pattern Ag consumed

- Climate FieldView (field boundaries and historical field data). Pattern Ag was a
  consumer of that API, not a publisher of one.
